# Certification éditoriale

Dans le cadre du projet Revues 3.0, j’avais proposé il y a deux ans (c. 2022) de travailler sur une modélisation des chaînes éditoriales.

Certains éditeurs anglo-saxons proposent des standards pour l’évaluation par les pairs qui permettent d’attester pour une publication du respect d’un certain nombre de standards. Leur utilisation peut déterminer l’octroi de certification qui peuvent justifier de la qualité d’une publication auprès de bailleurs.

Il n’existe toutefois pas de modèle unique qui détermine fondamentalement la qualité d’une publication. La variété des processus éditoriaux mérite d’être reconnue.

Afin d’accompagner les revues tant dans le choix d’un modèle éditorial que dans la valorisation du travail réalisé, nous proposons de développer un modèle modulaire qui permette de formaliser le choix et la description d’un processus éditorial.

Il s’agit donc de proposer une modélisation des processus éditoriaux et leur implémentation sous la forme d’un formulaire à embranchement. Le renseignement des informations débouche sur la production d’une description standardisée du processus éditorial d’une publication qui peut être partagée sous la forme d’une déclaration (à la manière des licences creative commons).

Surtout, le modèle éditorial développé pourrait être implémenté informatiquement en un outil de gestion éditoriale. En effet, il n’existe pas réellement d’outils qui permette d’accompagner le flux éditorial qui soit suffisamment génériques pour différents cas de figure. La configuration de flux éditoriaux à partir de ce modèle permettrait la configuration d’une brique logicielle à insérer dans une chaîne de travail numérique.
